# Auctioneer
Authors: Jonas, Marcus

## Summary

> Each night*, learn if an evil player traded tonight.

*Aaaaaaaand, sold to the robed stranger with the pitchfork!*

The Auctioneer encourages trading within the town, utilizing the mechanic to gain information on the alignment of the other players.

## How to run
Wake up the Auctioneer.
Show them yes if any evil player started the night with a 'Trade X' token.
Show them no otherwise.
Put them back to sleep.

## Examples
On the 1st day, 3 pairs of players announces that they wish to trade potions.
The Storyteller puts a 'Trade X' reminder token on each of those players.
The following night, Luna the Auctioneer wakes up.
Since 1 of the Reminder tokens is on the John the Aberration, an evil player, the Storyteller signals a Yes to the Auctioneer.

On day 2nd day, A pair of players announces that they wish to trade potions.
The Storyteller put a 'Trade X' reminder token on each of those players.
The following night, Chris the Auctioneer wakes up.
Since neither Reminder token is on an evil player, the Auctioneer learns a No.
