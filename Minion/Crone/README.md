# Crone
Authors: Jonas, Marcus

## Summary

> Each night if you traded with an evil player (not Travelers) you swap characters. If you traded with a good player you learn their character.

*Why, dearie! You ain't afraid of little old me, are you? Not when there are so much worse things, lurking in the dark?*

The Crone gathers information for the evil team and provides mobility for other players on their Team.

## How to run

When the Crone performs a Trade put down the **BEWITCHED** reminder token on the player they are trading with.
The following night wake the Crone.

If the **BEWITCHED** reminder token is on a good player show the Crone that player's character token.

If the **BEWITCHED** reminder token is on an evil player show them the **YOU ARE** info token and that player's character token.
Put the Crone to sleep.
Wake the player with the **BEWITCHED** reminder token and show them the **YOU ARE** info token and the Crone.
Put them back to sleep.
And swap the character tokens between the 2 players on the Grimoire.

Remove any **BEWITCHED** reminder tokens.
