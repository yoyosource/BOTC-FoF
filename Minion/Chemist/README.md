# Chemist
Authors: Jonas, Marcus

## Summary

> Each night, eye the cauldron; either choose 1) 2 potions to be traded, or 2) a good potion another player holds; you receive it, theirs break.

*Life is just chemicals. A drop here, a drip there, everything's changed.*
